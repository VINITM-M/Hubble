# Hubble.AI React Agent Hub

Premium responsive React/Vite implementation based on the supplied Hubble.AI reference and requirements.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Where to customize

- `src/main.jsx`: data-driven agent catalog, URLs, drawer content and interactions.
- `src/styles.css`: full visual system and responsive layout.

Replace the placeholder `example.com` agent URLs with the real configured launch URLs.
